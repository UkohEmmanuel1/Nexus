# Governance

## Project Structure

Nexus is an open-source community project. Decisions are made through consensus among maintainers.

## Maintainers

Maintainers are responsible for:
- Reviewing and merging pull requests
- Setting project direction
- Managing releases
- Enforcing code of conduct

## Decision Making

Major decisions (architecture changes, new features, API changes) are made through:
1. Discussion in GitHub issues
2. Community feedback period (minimum 1 week)
3. Maintainer vote

## Contributions

All contributions are welcome. See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines.
