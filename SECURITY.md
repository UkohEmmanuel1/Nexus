# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities by opening a GitHub Security Advisory or contacting the maintainers directly.

Do not report security vulnerabilities through public GitHub issues.

## Scope

- Model weights and checkpoints
- Tokenizer files
- Training and inference pipelines
- API endpoints

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | ✅        |
| older   | ❌        |
